RETURN Support

RETURN uses Apple's Screen Time frameworks to help you follow a gradual daily social-media allowance.

Protection is not starting

Open RETURN, go to Settings, confirm that at least one protected item is selected, and tap Refresh protection. Screen Time permission must remain enabled for RETURN in iOS Settings.

Test the shield

Go to Settings > Preview protection > Show protection now, then open a selected app. Return to RETURN and choose Remove preview shield when finished.

Reset RETURN

Settings > Reset RETURN removes local program data, the protected-app selection, active monitoring, and RETURN shields.
